## Sobre

Site pessoal com layout responsivo, seções de apresentação e projetos e foco em interfaces com HTML, CSS e JavaScript.

## Tecnologias e estrutura

| Caminho | Conteúdo |
| --- | --- |
| `index.html` | Página principal |
| `css/` | Estilos e responsividade |
| `js/` | Comportamentos interativos |
| `img/`, `icon/` | Identidade visual e imagens |

## Executar localmente

```bash
git clone https://github.com/HelioConde/portfolio2.0.git
cd portfolio2.0
python -m http.server 8000
```

Abra `http://localhost:8000`.
